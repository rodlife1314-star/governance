To set up continuous deployment for your new **governance** service in **europe-west2** (London) from your GitHub repository, use the following configuration and command.

### 1. Add `cloudbuild.yaml` to your repository
Create a `cloudbuild.yaml` file in the root of your `governance` repository:

```yaml
steps:
  # Build the container image
  - name: 'gcr.io/cloud-builders/docker'
    args: ['build', '-t', 'europe-west2-docker.pkg.dev/$PROJECT_ID/cloud-run-source-deploy/governance:$COMMIT_SHA', '.']
  
  # Push the container image to Artifact Registry
 ['push', 'europe-west2-docker.pkg.dev/$PROJECT_ID/cloud-run-source-deploy/governance:$COMMIT_SHA']
  
  # Deploy container image to Cloud Run
  - name: 'gcr.io/google.com/cloudsdktool/cloud-sdk'
    entrypoint: gcloud
    args:
      - 'run'
      - 'deploy'
      - 'governance'
      - '--image=europe-west2-docker.pkg.dev/$PROJECT_ID/cloud-run-source-deploy/governance:$COMMIT_SHA'
      - '--region=europe-west2'
      - '--platform=managed'
      - '--allow-unauthenticated'
```

### 2. Create the Cloud Build Trigger
Run this command to create the trigger (ensuring your GitHub repository is connected to Cloud Build):

```bash
gcloud beta builds triggers create github \
    --name="deploy-governance" \
    --project="gen-lang-client-0651940939" \
    --repo-owner="rodlife1314-star" \
    --repo-name="governance" \
    --branch-pattern="^main$" \
    --inline-config="cloudbuild.yaml"
```

This will automatically build and deploy your service to London on every push to `main`!
